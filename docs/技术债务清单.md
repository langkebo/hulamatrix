# 技术债务清单

## 优先级定义
*   **P0 (Critical)**: 严重影响安全性或核心功能，需立即解决。
*   **P1 (High)**: 影响开发效率或存在潜在性能瓶颈，需尽快排期。
*   **P2 (Medium)**: 代码风格或局部优化，可随功能迭代逐步解决。

## 清单列表

### ✅ 已解决

1.  ~~**Tauri 安全配置缺失**~~ (P0) ✅
    *   **位置**: `src-tauri/tauri.conf.json`
    *   **问题**: `security.csp` 设置为 `null`，且 `withGlobalTauri` 为 `true`。
    *   **风险**: 极高的 XSS 攻击风险，恶意脚本可直接调用系统 API。
    *   **解决方案**: 已配置严格的 CSP 策略，`withGlobalTauri` 设置为 `false`。

2.  ~~**本地 SDK 依赖 (Hard Link)**~~ (P1) ✅
    *   **位置**: `package.json` -> `"matrix-js-sdk": "workspace:*"`
    *   **问题**: 依赖本地文件路径，导致 CI/CD 构建困难，且版本管理混乱。
    *   **解决方案**: 已使用 pnpm workspace 管理 (`pnpm-workspace.yaml`)。

3.  ~~**ImRequestUtils 遗留代码**~~ (P1) ✅
    *   **位置**: `src/utils/ImRequestUtils.ts`
    *   **问题**: 被识别为遗留/Mock 代码，但仍被项目依赖。
    *   **解决方案**: 已完成 100% 迁移到新的模块化 API 服务。文件保留作为兼容性转发层。

### ✅ 已解决 (Phase 3)

4.  ~~**好友列表渲染性能**~~ (P1) ✅
    *   **位置**: `src/views/homeWindow/FriendsList.vue`
    *   **问题**: 好友列表每次状态变化都触发完全重渲染
    *   **解决方案**: 已添加 `v-memo` 指令，优化排序算法，添加防抖处理

5.  ~~**RTC 资源泄漏**~~ (P0) ✅
    *   **位置**: `src/hooks/useWebRtc.ts`
    *   **问题**: `onUnmounted` 未调用 `clear()` 释放 RTC 资源
    *   **解决方案**: 已添加 `clear()` 调用到 `onUnmounted`

6.  ~~**主题监听器泄漏**~~ (P1) ✅
    *   **位置**: `src/layout/left/hook.ts`
    *   **问题**: `watchEffect` 添加的事件监听器未在组件卸载时清理
    *   **解决方案**: 改用 `watch` 并添加 `onUnmounted` 清理逻辑

### P1 - 功能与性能

7.  **Sliding Sync 功能残缺**
    *   **位置**: `src/services/matrix/MatrixClientService.ts`

    *   **建议**: 评估后端支持情况，完成 Sliding Sync 的适配或彻底移除相关死代码，避免误导维护者。

### P2 - 代码质量与规范

5.  **类型定义不严格**
    *   **位置**: `src/services/matrix/MatrixClientService.ts` 及其他服务文件。
    *   **问题**: 存在 `any` 类型断言（如 `(window as any).__TAURI__`）。
    *   **建议**: 完善 TypeScript 类型定义，为 `window` 对象扩展全局类型声明。

6.  **重复的 API 调用逻辑**
    *   **位置**: 各个 Store 与 Service 之间。
    *   **问题**: 部分业务逻辑在 Store 和 Service 中偶合，缺乏统一的数据获取层。
    *   **建议**: 抽离统一的 Data Access Layer (DAL) 或利用 SDK 的封装能力。
